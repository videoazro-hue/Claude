We only look up this public address on the blockchain — no private key, seed phrase, or exchange login involved. A public address can't move funds, so this is read-only by design, not just by permission.

In Coinbase: Settings → API → New API key → select View (read-only) permission only. Never enable Trade or Send/Transfer.

In eToro's Builders Portal: create a key with Read permission only, never Trade. Note: eToro balance sync is newly added and not fully verified yet — your key is saved safely, but the first sync may show an error until this is confirmed.
